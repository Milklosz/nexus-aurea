# VELORA 2.0 — Living Room Home

Status: Draft, for owner review. Visual redesign of the Home screen. No native, Rust, credential or
controller-infrastructure changes.

## What it is

The "Cinema Minimal" direction, chosen from four explored directions
(`design/prototypes/COMPARISON.md`, spec: `design/prototypes/DESIGN_SPEC.md`).

- The selected app is the hero: its name (72 px at 1080p) and one functional line
  ("Filmy i seriale · Okno Edge Cinema").
- One generated, original background per app (no third-party artwork), crossfaded after a 220 ms
  debounce between exactly two image layers.
- Thin top line: 24h Warsaw clock, Zabrze weather (hidden when there is no reading, never invented;
  dimmed when the last reading is stale), and three entries: Szukaj, Pilot, Ustawienia.
- One dock of eight apps in the order Netflix, Disney+, HBO Max, Prime Video, YouTube, Steam,
  Playnite, Apple Music. Type-only wordmarks with one accented part; no logos.
- Focus language everywhere: a light plate with dark text. A tile that is remembered while focus is on
  the top bar or in Control Center is "selected" (short underline).
- Control Center, search, on-screen keyboard and gamepad diagnostics are restyled to the same language
  (a right-hand sheet on the TV safe area). Their behaviour is unchanged.

## Reverting to the previous Home (Grand Cinema)

The old components and styles are untouched. Resolution order: `?homeTheme=` in the URL → localStorage
`velora.homeTheme` → build-time `VITE_VELORA_HOME_THEME` → `living-room`.

- Per machine: set `localStorage["velora.homeTheme"] = "grand-cinema"` (WebView devtools) and restart.
- Per build: `VITE_VELORA_HOME_THEME=grand-cinema pnpm build`.
- For good: revert the PR; nothing else depends on it.

## Design system

`src/theme/living-room/tokens.css` is the single source of colour, spacing, type, radii, the one shadow,
motion and focus tokens. All lengths are reference px on a 1920×1080 canvas (`--lr-px`), so the layout
scales to 4K without media queries. `html.lr-theme` scales the root font size the same way so the
rem-based overlays stay readable at 4K. Only `transform` and `opacity` animate (WebView2 runs with GPU
compositing disabled). `prefers-reduced-motion` turns focus into a surface swap with no travel.

Background scenes are generated by `src/theme/living-room/scenes.ts` and pre-rendered to
`src/assets/scenes/*.webp` (3840×2160, ~50 KB each) with `node design/tools/render-scenes.mjs`.

## Behaviour changes outside the visual layer

- **Playnite tile.** Launches through the existing `launchManagedApp("playniteFullscreen")`. Apple Music
  moved to the end of the dock. Tests that assumed seven tiles were updated, not weakened.
- **Home top actions.** Left/right stay inside the row, confirm presses the focused action (it must not
  launch the dock app), up/down are the existing zones. Control Center opened from an action returns
  focus to that action. `useNavigation` gained an optional `onHorizontalZone`; with no handler, its
  behaviour is identical, and the confirm key on a `.home-actions` button is left to the button.
- **Control Center** accepts `initialPanel` and `livingRoom` props (Szukaj/Pilot open the right tab;
  Polish section names and focus on the open tab). Defaults keep the old behaviour.
- `useWeather` also returns `temperatureText`, `condition`, `stale` (additive).

## How to look at it

```bash
pnpm install && pnpm dev    # http://127.0.0.1:1420 (no Tauri: launches report an error toast)
node design/tools/shoot.mjs http://127.0.0.1:1420/ design/screens --sizes 1920x1080,3840x2160 --steps "home:|next:ArrowRight"
```

Screenshots from the review are in `design/screens/` (1080p and 4K, all eight scenes, sheets, and the
fallback theme). Prototypes: `design/prototypes/*.html`.

## Known limitations

- Not run on the MSI / TV. Contrast, banding of the dark gradients and the 4K crossfade cost with GPU
  compositing disabled are unmeasured. The spec lists a fallback ladder if the crossfade drops frames.
- Frame rate was not measured; no 60 FPS claim is made.
- Native DualShock 4 support (Sprint S1) is not part of this change. The design works through the
  existing input abstraction (keyboard, the gamepad hook, the iPhone remote commands).
- Control Center still contains its legacy content structure (cards, the footer actions Diagnostyka /
  Pokaż pulpit / Wróć do VELORA). The tab "Kino" contains a profile button still named "Cinema".
- Scenes remain one family (horizons, glows, terrain vary; there is no per-app composition type).
